01FINTECH / INTEGRATION

MoneyGram Integration Platform

Backend empresarial para integrar aplicaciones internas con servicios MoneyGram mediante SOAP y AgentConnect.

¿Qué hace?

Centraliza el flujo de remesas: consulta catálogos y tarifas, valida datos de envío o cobro, ejecuta operaciones contra MoneyGram y normaliza respuestas a JSON, conservando auditoría de cada transacción.

JavaSpring BootSOAPPostgreSQLDocker
02COMPLIANCE / PLATFORM

PLD / FT Universal Platform

Plataforma multi-tenant para prevención de lavado de dinero, riesgo e integración empresarial.

¿Qué hace?

Recibe clientes y operaciones desde otros sistemas, ejecuta reglas PLD/FT, calcula riesgo, genera alertas e integra servicios de Machine Learning sin quedar amarrada a un solo core.

NestJSAngularPythonRabbitMQKeycloak
03FINANCIAL CORE

CenterDivisa

Plataforma financiera para centros cambiarios y cumplimiento regulatorio.

¿Qué hace?

Administra clientes, operaciones y sucursales, aplica reglas de negocio y automatiza reportes regulatorios FD1/DE1 mediante generación XML y validación XSD.

Node.jsPostgreSQLXMLXSDDocker
04BUSINESS SYSTEM

Enterprise POS Platform

Punto de venta multiempresa y multisucursal para tiendas y restaurantes.

¿Qué hace?

Controla apertura de caja, turnos, ventas, compras y promociones; en restaurantes mantiene comandas abiertas y distribuye productos hacia cocina o bebidas según su área de preparación.

Node.jsExpressAngularSequelizePostgreSQL
05WEB / DEVOPS

Axen Union Platform

Ecosistema web con varios frontends y backends detrás de infraestructura contenerizada.

¿Qué hace?
